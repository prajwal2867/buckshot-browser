# Buckshot Roulette Browser CLI

This is a browser-based JavaScript version of the terminal game. It runs locally
without a server, build step, or additional packages.

## Run locally

Open `index.html` in a browser and press Enter to start. Type a numbered choice
in the command line at the bottom, then press Enter. The dealer waits 10 seconds
before its turn.

For static hosting, upload the contents of this folder to a host such as GitHub
Pages, Netlify, or Vercel.
